# road-pothole-detection
Real-time pothole detection across urban, rural and mountainous road scenes with YOLOv8, trained on a self-built multi-scenario dataset. mAP@0.5 74.26% at 61.27 FPS with only 3.0M parameters and 8.1 GFLOPs, deployable on embedded devices for assistive road-safety systems.
